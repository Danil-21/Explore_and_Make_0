# Explore and make 0

## Описание проекта

Это backend-приложение для управления проектами и задачами внутри команды, реализованное с использованием Django REST Framework.

Система позволяет:

* регистрировать пользователей
* создавать проекты и управлять участниками
* создавать и отслеживать задачи
* контролировать доступ к данным через систему ролей
* фильтровать задачи

---

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <https://github.com/Danil-21/Explore_and_Make_0.git>
cd <ExploreAndMake0>
```

---

### 2. Применение миграций

```bash
python manage.py migrate
```

---

### 3. Создание суперпользователя (опционально)

```bash
python manage.py createsuperuser
```

---

### 4. Запуск сервера

```bash
python manage.py runserver
```

---

## Основной функционал

### Пользователи

* регистрация через API (`/register/`)
* аутентификация через Django session

---

### Проекты

* создание проектов
* добавление участников
* доступ только для участников проекта

---

### Задачи

* создание задач внутри проекта
* указание автора и исполнителя
* статусы, приоритеты, дедлайны

---

### Права доступа

* владелец проекта управляет всеми задачами
* исполнитель может менять статус и приоритет
* автор может редактировать описание и удалять задачу
* посторонние пользователи не имеют доступа

---

### Фильтрация

Примеры запросов:

```http
GET /tasks/?status=сделать
GET /tasks/?priority=высокий
GET /tasks/?performer=1
GET /tasks/?project=1
```

---

### Пагинация

```http
GET /tasks/?page=1
```

## Документация API

Документация генерируется автоматически с помощью drf-spectacular:

* Swagger UI — интерактивное тестирование API
* ReDoc — удобное чтение документации

---

## Архитектура проекта

* **Models** — структура данных
* **Serializers** — валидация и преобразование данных
* **ViewSets** — обработка запросов
* **Permissions** — контроль доступа
* **Filters** — фильтрация данных
